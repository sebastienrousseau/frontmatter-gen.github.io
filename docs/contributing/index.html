Contributing to Frontmatter Gen

Guidelines for bug reports, pull requests, local quality gates, and DCO sign-offs.

Contributions to both the frontmatter-gen Rust crate and the frontmatter-gen.github.io documentation portal are welcome under our dual Apache-2.0 OR MIT license.

01

Rust Crate Quality Gates (`frontmatter-gen`)

Every pull request to the Rust crate must pass the full local verification battery before review:

bash — crate verification battery
$cargo fmt --all -- --check
$cargo clippy --all-targets --all-features -- -D warnings
$cargo test --all-features
$MIRIFLAGS="-Zmiri-strict-provenance -Zmiri-tree-borrows -Zmiri-symbolic-alignment-check" cargo +nightly miri test --lib --locked
$reuse lint
02

Documentation Portal Quality Gates (`frontmatter-gen.github.io`)

Build the static site and run the 15-gate ssg audit, WCAG 2.2 AAA contrast verification, and regression test suite:

bash — website verification battery
$make build
$make verify
03

Versioning, Commits & DCO Sign-Off

All repositories follow strict versioning and commit standards:

Standard Requirement Verification
Semantic Versioning Releases increment strictly by +0.0.1 on feat/vX.Y.Z branches. Verified by verify-release-versions.sh
Conventional Commits Imperative subject line (max 50 chars) with SSH/GPG signature (-S). Enforced by commitlint & branch protection
DCO & SPDX Signed-off-by trailer (-s) and SPDX license headers on all files. Verified by reuse lint & DCO check
