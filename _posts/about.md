<h2>Engineering Pedigree &amp; Ecosystem</h2>

<p>Frontmatter Gen is part of a cohesive ecosystem of pure-Rust libraries engineered for static site compilation, structured metadata extraction, and standards-compliant parsing:</p>

<ul>
<li><strong>Frontmatter Gen (<code>frontmatter-gen</code>):</strong> Zero-copy frontmatter extraction and multi-format parsing for YAML 1.2, TOML 1.1, and JSON with HTML meta tag synthesis and 100% unit test coverage.</li>
<li><strong>Noyalib (<code>noyalib</code>):</strong> Pure-Rust YAML 1.2 parser and serializer with zero <code>unsafe</code> code, configurable DoS budgets, and explicit YAML tag preservation.</li>
<li><strong>Static Site Generator (<code>ssg</code> / <code>staticdatagen</code>):</strong> Rust static site compiler with built-in WCAG AAA contrast auditing, Subresource Integrity (SRI), and CycloneDX SBOM generation.</li>
<li><strong>Skeletonic CSS:</strong> Accessible, token-driven CSS design system engineered for WCAG 2.2 Level AAA compliance across light and dark modes.</li>
<li><strong>Personal Website &amp; Research:</strong> Visit <a href="https://sebastienrousseau.com/">sebastienrousseau.com</a> for technical articles, architecture notes, and open-source releases.</li>
</ul>
